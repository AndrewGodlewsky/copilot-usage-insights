MCP-specific: failures are recorded tool outcomes, not necessarily connectivity failures or server bugs. Unknown completions are not failures. Recommend checking one repeatedly failing integration's configuration or arguments; do not invent an error cause. Tool-definition tokens measure advertised schemas, not returned results or wasted calls. Trial selective integration loading only when the integration is irrelevant to a comparable task, then compare matched input and task completeness. Low failure rates can describe reliable observed calls, not uptime.
