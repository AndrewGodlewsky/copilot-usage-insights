MCP-specific: tool failures are recorded outcomes, not proof of connectivity or server bugs; unknown completions are not failures. Repeated identical reads/searches can be legitimate after edits or compaction. For consecutive failure stretches or repeatedly failing integrations, suggest checking configuration, permissions, or arguments rather than inventing a cause. Tool definitions measure advertised schemas, not results or wasted calls. Trial selective integration loading only when irrelevant to a comparable task, comparing matched input and completeness. Low failure rates describe observed calls, not uptime.
