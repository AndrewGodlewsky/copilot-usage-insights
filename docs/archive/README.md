# Historical development archive

These 45 plans and specifications record the work that shaped Usage Insights. They preserve design rationale and execution history; they are not current instructions, release approvals, or an outstanding task list. Version numbers, prototype names, and task statuses refer to the original work. Some local prototypes were never part of this repository.

Start with the [reviewer’s guide](../reviewing.md), [documentation index](../README.md), and [decision backlog](../audit-followups.md) for current behavior and remaining choices. Durable accounting and privacy rules are summarized in the reviewer’s guide; detailed research remains in the [research index](../research/README.md).

The archive retains the original documents and their links. Future development plans should live with active work and move here when they become historical; update the index and links when moving them.
