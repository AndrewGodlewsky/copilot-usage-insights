How to read this page
Averages use only requests with the relevant measurement recorded. Credits per request excludes partial and missing charges; recorded zero charges are included. Cache reuse is cache-read input divided by total input from requests with a complete cache split.
Input always includes cached context, regardless of Include cache tokens. Output includes reported reasoning. Date, model, project, and session filters apply. Daily bar selection does not change this view.
Review rules: low cache reuse means below 50% across at least 5 measured requests and 50K input tokens, with 80% coverage. Increasing input means at least 2× and 10K more tokens between the median of the first and last three requests in the selected range, with 6 measurements and 80% coverage. Comparisons stay within one project, session, model, and initiator; subagents and overlapping sample timestamps are excluded. Credit concentration means at least 60% of complete charges on one model, 80% overall charge coverage, and at least two models with 5 complete charges each.
Tool definitions are already part of input, not tool results. A tool-overhead finding requires at least 5 matched samples, 80% coverage, 1K definition tokens per request and 10% of input. MCP findings require at least 3 failed calls; their failure rate excludes unknown outcomes. Current-context sources may overlap and are not added together. These rules identify places to investigate, not optimal targets or proof of waste. No score, task success, or savings estimate is inferred. AI review
Uses your existing GitHub sign-in. Reconnect verifies a new helper connection without sending a prompt.
If sign-in is needed, sign in to Copilot and GitHub CLI (gh auth login) with the same account, then reconnect. Credentials are never saved in this plugin.
Copilot sources
The default Copilot home is scanned automatically.
Automatically finds standard Copilot homes in running WSL distributions. Stopped distributions are listed in Local data sources; start them and refresh to include their history. VS Code Server storage is discovered alongside CLI homes.
Reads retained Copilot debug logs, including recorded AI credits. Logging may need to be enabled in VS Code; missing history cannot be reconstructed. Only calls with explicit Copilot charges are included. See the repository README for setup.
Use the User folder containing workspaceStorage or globalStorage. Custom folders are read even with automatic VS Code discovery off. Disabled source folders below also apply to VS Code folders.
Use a Copilot home containing session-state and/or session-store.db. Mounted or copied homes work too. For a custom WSL location, use a Windows path such as \\wsl.localhost\Ubuntu\home\your-user\.copilot. Explicit paths are read even when automatic discovery is off.
